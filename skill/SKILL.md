# サーバーは srv で立てる

人に見せるサーバーは、`npm run dev &` や素の `tailscale serve` で立てない。**`srv add` で立てる。**
「起動のしかた」が台帳に残るので、マシンを再起動しても画面のボタン 1 つで戻せる。リンクも一覧に並ぶ。

```sh
srv port                                    # 空いているポートを 1 つ出す(7500 から)
srv add <名前> --port P [--note "何の画面か"] -- <起動コマンド…>
srv ls                                      # 状態つきの一覧
srv logs <名前>                              # tmux の最後の行
srv stop|start|restart <名前>                # stop は公開も外す(start で同じ URL に戻る)
srv rm <名前>                                # 止めて、公開を外して、台帳から消す
srv fav <名前> [--off]                       # お気に入り(画面の最初のタブ)
srv share <名前> [--minutes 60] [--off]      # trycloudflare で外に公開(時間で自動で止まる)
srv ui                                      # 一覧の画面の URL(立っていなければ立てる)
```

`srv add` は次をまとめてやる。最後の行に URL を出す。
1. 台帳に書く
2. tmux セッション `srv-<名前>` で起動する
3. 返事が来るまで待つ(落ちたらログの最後を出して止まる)
4. `tailscale serve --https=P` で tailnet に出す

その URL を**そのまま**ユーザーに返す(ts.net のまま。スマホから開くため)。

## 書き方

- **名前**: 英小文字・数字・`-` `_`。何の画面か分かる名前にする(`blog-preview`、`admin-ui` など)。同じ名前で add し直すと上書きになる
- **起動コマンド**: 今のフォルダ(`--cwd` で変えられる)から、そのまま再現できる形で書く
  - サーバーは**前で動き続ける**コマンドにする(`&` や `nohup` を付けない。tmux が面倒を見る)
  - ポートは決め打ちにする(vite なら `--port P --strictPort`)。勝手に次の番号へずれると、台帳とずれる
  - 待つアドレスは `127.0.0.1` か `localhost` でよい。外へは tailscale serve が出す
- **`--note`**: 一覧に出す一言。「何の画面か」を書く
- **秘密**: 台帳に書かない。`--env-file path/to/.env` で場所だけ渡す。秘密でない値は `--env K=V`
- **`--path /foo`**: 開く場所が `/` でないとき。起動の確認もこのパスで行う
- **`--by`**: 立てたセッションやプロジェクトの名前。画面の「新規」に出る(既定は起動フォルダの名前)
- **`--fav`**: ユーザーが常用すると言ったものだけ付ける。ふだんは付けない(★ はユーザーが画面で付ける)
- **`--autostart`**: ログイン時にも立てたい常用のものだけ付ける
- **`--no-start`**: もう動いているものを、後から登録だけするとき
- **`--https-port H`**: tailnet に出す番号を変えたいとき(既定は `--port` と同じ番号)。守る番号(既定 443)は選べない

## 例

```sh
cd ~/src/my-blog
srv add blog-preview --port 4321 --note "ブログの下書きプレビュー" -- npx astro dev --port 4321
```

## 外に公開する(tailnet の外の人に見せる)

「外から見られるようにして」「URL を人に渡したい」と頼まれたら、`cloudflared tunnel` を自分で立てずに `srv share <名前>` を使う。
- 出てきた `https://….trycloudflare.com` をそのまま返す
- 何分で止まるかを添える(既定 60 分、`--minutes` で変えられる)
- 誰でも開けることを一言添える
- 頼まれていないのに外へ出さない。ファイルを消せる画面など、危ないものは出す前にユーザーに確かめる

## してはいけないこと

- 守る番号(既定 443。`SLL_RESERVED_PORTS`)の公開に触らない。srv も触らない
- ほかのセッションが登録したサーバーを、頼まれずに止めたり消したりしない
- 片付けのタブにある「宛先の止まった公開」を勝手に外さない。ユーザーが画面で選ぶ

## 画面

`srv ui` が出す URL(`https://<マシン名>.<tailnet>.ts.net:7463/`)。

- 下に 3 タブ: お気に入り(★ を付けたもの)/ 新規(登録の新しい順)/ 片付け
- 押すとそのページへ飛ぶ。止まっていれば起動してから飛ぶ。⋯ か長押しで、停止・外に公開・ログ・削除などのシート
- 片付けのタブ: 長く止まっているもの、台帳に無いのに動いているもの(下書きで登録できる)、宛先の止まった公開(外せる)

画面から登録した下書きは、拾ったコマンドがそのまま入っている(`node …/vite …` など)。
「直して」と頼まれたら、正しい形で `srv add <同じ名前> --port … -- <コマンド>` をし直す(上書きになり、下書きの札も外れる)。

## つまずいたら

- `ポート P は別のプロセスが使っている`: `lsof -nP -iTCP:P` で誰が使っているかを見て、ユーザーに伝える。勝手に止めない
- `落ちた` / `返事が無い`: `srv logs <名前>` を見る。コマンドの誤りが多い
- 台帳の実物: `~/.config/simple-localserver-list/servers/<名前>.json`
