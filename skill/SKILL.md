# サーバーは srv で立てる

人に見せるサーバーは、`npm run dev &` や素の `tailscale serve` で立てない。**`srv add` で立てる。**
「起動のしかた」が台帳に残るので、Mac を再起動しても画面のボタン 1 つで戻せる。リンクも一覧に並ぶ。

```sh
srv port                                    # 空いているポートを 1 つ出す(7500 から)
srv add <名前> --port P [--note "何の画面か"] -- <起動コマンド…>
srv ls                                      # 状態つきの一覧
srv logs <名前>                              # tmux の最後の行
srv stop|start|restart <名前>
srv rm <名前>                                # 止めて、公開を外して、台帳から消す
```

`srv add` は次をまとめてやる。最後の行に URL を出す。
1. 台帳に書く
2. tmux セッション `srv-<名前>` で起動する
3. `tailscale serve --https=P` で出す
4. 返事が来るまで待つ

その URL を**そのまま**ユーザーに返す(ts.net のまま。スマホから開くため)。

## 書き方

- **名前**: 英小文字・数字・`-` `_`。何の画面か分かる名前にする(`admin-ui`、`my-game` など)。同じ名前で add し直すと上書きになる
- **起動コマンド**: 今のフォルダ(`--cwd` で変えられる)から、そのまま再現できる形で書く
  - サーバーは**前で動き続ける**コマンドにする(`&` や `nohup` を付けない。tmux が面倒を見る)
  - ポートは決め打ちにする(vite なら `--port P --strictPort`)。勝手に次の番号へずれると、台帳とずれる
  - 待つアドレスは `127.0.0.1` か `localhost` でよい。外へは tailscale serve が出す
- **`--note`**: 一覧に出す一言。「何の画面か」を書く
- **秘密**: 台帳に書かない。`--env-file path/to/.env` で場所だけ渡す。秘密でない値は `--env K=V`
- **`--path /foo`**: 開く場所が `/` でないとき。起動の確認もこのパスで行う
- **`--autostart`**: ログイン時にも立てたい常用のものだけ付ける
- **`--no-start`**: もう動いているものを、後から登録だけするとき
- **`--https-port H`**: tailnet に出す番号を変えたいとき(既定は `--port` と同じ番号)。443 は選べない

## 例

```sh
cd ~/src/my-game
srv add my-game --port 5274 --note "ゲームの試作" -- npx vite --port 5274 --strictPort
```

## してはいけないこと

- 443 番の公開(ほかの道具)に触らない。srv も触らない
- ほかの人(ほかのセッション)が登録したサーバーを、頼まれずに止めたり消したりしない
- 画面の「公開だけ残っている」を勝手に外さない。ユーザーが画面で選ぶ

## 画面

サーバー台帳: `https://my-mac.tail1234.ts.net:7463/`

- 一覧、起動・停止・再起動・ログ・削除ができる
- 「未登録で動いている」(srv の外で立てたもの)を下書きで登録できる
- 「公開だけ残っている」(宛先が止まった tailscale の公開)を外せる

画面から登録した下書きは、拾ったコマンドがそのまま入っている(`node …/vite …` など)。
ユーザーに「直して」と頼まれたら、正しい形で `srv add <同じ名前> --port … -- <コマンド>` をし直す(上書きになり、下書きの札も外れる)。

## つまずいたら

- `ポート P は別のプロセスが使っている`: `lsof -nP -iTCP:P` でユーザーを見て、本人(ユーザー)に伝える。勝手に止めない
- `返事が無い`: `srv logs <名前>` を見る。コマンドの誤りが多い
- 台帳の実物: `~/.config/simple-localserver-list/servers/<名前>.json`
- コードの場所: `~/src/simple-localserver-list`
